SHOP SCHEDULE GENERATOR — 使い方

年月を選んで日ごとの営業時間を入力するだけで、スケジュールカレンダーが自動生成されます。
「画像として保存」でPNG書き出し → そのままSNS投稿に使えます。

STEP 01

年・月を選ぶ

画面上部のセレクターで対象の年と月を選択します。2024年〜2035年まで対応しています。

STEP 02

一括入力を活用する

「一括編集」エリアの曜日ボタン（日・月・火…）をクリックすると該当曜日の全日付にチェックが入ります。時間を入力して「適用」を押すと一括設定できます。

STEP 03

プリセットを使う

「通常営業」「CLOSE」などのプリセットボタンを押すと、チェック中の日付にまとめて適用されます。特殊な日は個別に上書きしてください。

STEP 04

個別に調整する

各日付の APPAREL・BAR 欄を直接編集できます。CLOSE（大文字）で赤表示、貸切営業などの文字で緑表示になります。

STEP 05

データを保存する

「データ保存」ボタンを押すとブラウザにデータが保存されます。次回開いたときに自動で復元されます。月ごとに保存し直してください。

STEP 06

画像として書き出す

「画像として保存」を押すと wansie_schedule_YYYY_MM.png（4300×4300px）がダウンロードされます。そのままSNSに投稿できます。

入力ルール

  • 営業時間は 14–19 のように半角数字＋半角ハイフンで入力
  • 休業日は CLOSE（必ず大文字）と入力 → カレンダーで赤表示
  • 特記事項（貸切・イベント名など）はそのまま文字で入力 → 緑色で表示
  • 「データ保存」は月が変わるたびに押し直してください（最後に保存した月のデータが残ります）
  • チェックボックスで複数日をまとめて選択し、一括編集・プリセット適用が可能です

CLAUDE CODE でカスタマイズする場合

このHTMLファイルの先頭にある :root {} 内の変数を変えるだけで、デザイン全体を調整できます。

/* wansie_schedule_app.html — :root {} を編集 */ --color-brand: #1a1a1a; /* メインカラー */ --color-accent: #c0392b; /* CLOSEの赤 */ --color-accent-alt: #27ae60; /* 特記事項の緑 */ --color-sun: #c0392b; /* 日曜カラー */ --color-sat: #2c4a8a; /* 土曜カラー */ --cal-month-size: 52px; /* 月の大きい数字 */ --cal-title-size: 20px; /* タイトル文字サイズ */

Claude Codeで開いて「赤をブランドカラーの〇〇に変えて」「フォントをGeorgiaにして」など自然な言葉で指示できます。
